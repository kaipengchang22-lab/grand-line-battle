# 伟大航路：本部决战

由 Codex 直接编写的手机横屏第一人称 3D 动作游戏。项目采用原生 HTML、CSS、JavaScript 与 Three.js，不依赖付费生成平台。

## 当前可玩内容

- 第一人称镜头：左侧摇杆移动，右侧滑动转向
- 电脑控制：WASD、鼠标、J/K/U/I/O/空格
- 普通攻击、闪避、连环拳风、冲击飞拳、热血爆发、震慑领域
- 晴天、阴天、降雨天气循环；实例化三维海岸浪花、天空海鸥、低模植物和海军炮台
- 剑兵、枪兵、盾兵、队长与多阶段首领
- 8 秒据点占领、首领战、30 秒盟友防守与撤离
- 高清透明角色动作贴图：待机、走路、橡胶拳攻击、受击
- 敌兵已停止使用旧 2D 行走/攻击图集；剑兵、枪兵、盾兵、队长和赤犬使用模型库中的真实 FBX，并由骨骼节点驱动待机、移动、攻击、受击和技能姿势
- 第一人称技能动作：普通拳、连环拳、飞拳、爆发、战斧、火箭、巨人拳、霸气与闪避均有独立姿势和连续过渡
- 角色骨骼与蒙皮网格统一站立坐标并重建绑定姿态；路飞移动朝行进方向、攻击朝瞄准方向，赤犬保留独立技能预备/释放姿势
- 第一人称与世界空间技能特效：FBX 蒙皮手臂跟随实际攻击姿势，立体能量核心、厚冲击环、碎片与锥形拖尾随命中和镜头震动同步
- 2.5D立体角色层：高清贴图叠加深度轮廓、动态脚下阴影、移动起伏和受击闪光，保留轻量手机性能
- Spine 风格轻量骨骼层：根骨、骨盆、躯干、胸口、头部、双臂和双腿按 30fps 插值驱动贴图层
- 路飞真实 Spine 运行时资源首版：`assets/spine/luffy/luffy.json`、`luffy.atlas` 与透明 WebP 部件图集，含待机/行走/攻击/受击/连击/飞拳/霸气/巨人拳时间轴；V20 已把帽子、头、躯干、双臂、双手、腰带、短裤和双腿真正挂到可见骨骼层
- Z 深度与轮廓光：主贴图、深度背层、青色边缘光分层渲染，随动作/受击/强化状态动态变化
- 细节化港口场景：起伏海面网格、分层岸浪与同步飞溅、按树高变化的树冠、冰片、码头桩、堡垒灯塔与窗光
- 第一人称手臂直接镜像 Film Red 模型骨骼动作，按动作周期释放立体特效并施加镜头后坐
- 程序化港口、冰面、军舰和低面数三维冲击特效
- 手机性能限制、横屏提示、PWA 主屏幕安装支持
- 第一人称与俯视角随时切换

## 运行

直接打开 index.html 需要联网载入 Three.js。部署到 GitHub Pages 后，用手机浏览器横屏访问即可。

运行角色、Boss 与环境回归检查：先执行 `npm install`，再执行 `npm test`。

角色测试：普通地址沿用稳定版，`?model=original` 加载原有免费 GLB；`?model=rigged-luffy&v=3` 加载带 16 节骨骼、蒙皮、内嵌贴图与 `Idle/Walk/Attack` 动作的 3D GLB。默认 Film Red 模型在第一人称中显示单独镜像的真实蒙皮手臂，加载失败时使用简化三维手臂。安卓手机仍需实机检查帧率、发热、外观和朝向。模型由本项目脚本生成，公开展示授权由项目所有者确认。

说明：V20 在保留现有高清动作贴图作为移动端安全回退的同时，加入可被 Spine 4.2 运行时读取的路飞 JSON/Atlas/WebP 资源，并让它的数据时间轴驱动可见的部件骨骼层。加载完成后会隐藏旧整图；若网络或浏览器不支持 WebP，则自动回退整图，不会再次出现纯色空场景。后续替换为 Spine 编辑器导出的正式部件，只需保持槽位名称不变。

海军动作图集的帧布局与文件名见 `assets/marine-animation-atlas.json`，每张图按从左到右、从上到下读取 8 个等分帧。敌兵状态机为：待机（行走图第 1 帧）→接近时行走循环→攻击/射击 1 秒动作→命中帧结算→回到待机；受击会短暂闪红并可被控制技能打断。盾兵与本部首领保留程序化 3D 专属模型和招式。
