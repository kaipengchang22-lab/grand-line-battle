# 伟大航路：本部决战

由 Codex 直接编写的手机横屏第一人称 3D 动作游戏。项目采用原生 HTML、CSS、JavaScript 与 Three.js，不依赖付费生成平台。

## 当前可玩内容

- 第一人称镜头：左侧摇杆移动，右侧滑动转向
- 电脑控制：WASD、鼠标、J/K/U/I/O/空格
- 普通攻击、闪避、连环拳风、冲击飞拳、热血爆发、震慑领域
- 剑兵、枪兵、盾兵、队长与多阶段首领
- 8 秒据点占领、首领战、30 秒盟友防守与撤离
- 高清透明角色动作贴图：待机、走路、橡胶拳攻击、受击
- 海军小兵高清动作图集已接入敌兵状态机：剑兵/队长行走与佩刀攻击、枪兵行走与步枪射击，均按 8fps 播放并在命中帧结算
- 第一人称技能动作：普通拳、连环拳、飞拳、爆发、战斧、火箭、巨人拳、霸气与闪避均有独立姿势和连续过渡
- 第一人称技能特效：镜头内斩击线、冲击环、光晕、火焰色阶与霸气紫蓝色阶，并与世界空间爆发/冲击波同步
- 2.5D立体角色层：高清贴图叠加深度轮廓、动态脚下阴影、移动起伏和受击闪光，保留轻量手机性能
- Spine 风格轻量骨骼层：根骨、骨盆、躯干、胸口、头部、双臂和双腿按 30fps 插值驱动贴图层
- Z 深度与轮廓光：主贴图、深度背层、青色边缘光分层渲染，随动作/受击/强化状态动态变化
- 细节化港口场景：冰面裂纹与立体冰片、海水波纹/泡沫、码头桩、堡垒灯塔、窗光与轮廓补光
- 第一人称动作使用双帧交叉淡化、缓入缓出、镜头后坐与动作打断，出拳更连贯
- 程序化海军、武器、港口、冰面、军舰和特效
- 手机性能限制、横屏提示、PWA 主屏幕安装支持
- 第一人称与俯视角随时切换

## 运行

直接打开 index.html 需要联网载入 Three.js。部署到 GitHub Pages 后，用手机浏览器横屏访问即可。

说明：当前角色素材仍是已有的扁平动作贴图，因此 V18 采用可替换的 Spine 风格轻量骨骼/附件层来实现 30fps 插值、Z 深度与轮廓光；本版同时修复了海军贴图动画首帧的运行时错误，避免启动后只显示纯色背景。后续拿到真正的 Spine JSON/Atlas 时可直接替换附件，不需要改战斗逻辑。

海军动作图集的帧布局与文件名见 `assets/marine-animation-atlas.json`，每张图按从左到右、从上到下读取 8 个等分帧。敌兵状态机为：待机（行走图第 1 帧）→接近时行走循环→攻击/射击 1 秒动作→命中帧结算→回到待机；受击会短暂闪红并可被控制技能打断。盾兵与本部首领保留程序化 3D 专属模型和招式。
